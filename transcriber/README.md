# 무제한 전사기

녹음·영상 파일을 **길이 제한 없이** 한국어 텍스트로 바꿉니다.
내 컴퓨터나 Google Colab에서 음성인식 모델(OpenAI Whisper large-v3 계열)을 직접 돌리기 때문에
파일당 길이 제한, 월 사용량 제한, 업로드 용량 제한이 없습니다. 10시간짜리 파일도 됩니다.
녹음이 외부 서버로 나가지 않으므로 민감한 내용(미공개 콘텐츠, 게스트 인터뷰, 통화)도 안심하고 돌릴 수 있습니다.

- 입력: mp3, m4a, wav, mp4, mov 등 거의 모든 음성·영상
- 출력: 문단 본문(txt), 타임스탬프 본문(txt), 자막(srt), 원본 데이터(json)
- 중간에 꺼져도 같은 명령을 다시 실행하면 완료된 구간은 건너뛰고 이어서 합니다

## 어떤 방법을 고를까

| 내 상황 | 방법 | 비용 |
|---|---|---|
| 컴퓨터에 NVIDIA 그래픽카드가 있다 | 방법 0 (창 프로그램) | 무료 |
| 그래픽카드가 없고, 오래 걸려도 괜찮다 | 방법 0 (창 프로그램, CPU) | 무료 |
| 그래픽카드가 없고, 빨리 끝내고 싶다 | 방법 2 (Colab 무료 GPU) | 무료 (용량 큰 파일은 Drive 공간 필요) |
| 녹음 내용이 민감해서 외부로 보내면 안 된다 | 방법 0 (창 프로그램) | 무료 |

속도는 장비마다 크게 달라서 숫자로 단정하지 않습니다. 실행하면 화면에 `처리 속도 n배속`이 찍히므로 첫 구간이 끝나면 전체 예상 시간을 바로 알 수 있습니다.
경험적으로 GPU는 실시간의 수십 배, 일반 노트북 CPU는 실시간과 비슷하거나 더 느립니다 (검증 필요: 장비별로 직접 확인).

## 방법 0 (가장 쉬움): 창 프로그램

1. 파이썬 설치 (3.10 이상): https://www.python.org/downloads/ → Windows는 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 이 폴더(`transcriber`)를 통째로 내 PC에 내려받기
3. **Windows**: `전사하기.bat` 더블클릭 → 창이 열립니다
   **Mac**: 터미널에서 이 폴더로 이동해 `chmod +x 전사하기.command`를 한 번 실행한 뒤, `전사하기.command` 더블클릭 (보안 경고가 뜨면 우클릭 → 열기)
4. [파일 추가] → [전사 시작]. 진행 상황이 창에 표시되고, 끝나면 [결과 폴더 열기]
   - 처음 한 번은 패키지와 모델 내려받기(1.5~3GB)로 몇 분 걸립니다
   - [중지]를 누르면 현재 구간만 버리고 멈추며, 다시 [전사 시작]하면 이어서 합니다


### Windows
1. 파이썬 설치 (3.10 이상 권장): https://www.python.org/downloads/ → 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 이 폴더(`transcriber`)를 통째로 내 PC에 내려받기
3. 음성 파일(또는 폴더)을 **`전사하기.bat` 위로 끌어다 놓기** (창 없이 바로 전사)
   - 처음 한 번은 패키지 설치(몇 분)와 모델 내려받기(약 1.5GB 내외, 검증 필요)가 자동으로 진행됩니다
4. 끝나면 음성 파일 옆에 `전사결과` 폴더가 생깁니다

### Mac
```bash
cd transcriber
./전사하기.command "녹음.m4a"
```
(터미널에 `./전사하기.command `까지 입력한 뒤, 파일을 터미널 창으로 끌어다 놓고 Enter)

### 직접 명령으로 (Windows/Mac 공통)
```bash
pip install -r requirements.txt
python transcribe.py "녹음.m4a"                       # 기본 실행
python transcribe.py "녹음폴더"                        # 폴더 안 파일 전부
python transcribe.py "강의.mp4" --prompt "브랜드명, 강사 이름, 제품명"   # 고유명사 힌트
python transcribe.py "녹음.m4a" --model small          # 빠른 미리보기 (정확도 낮음)
python transcribe.py "녹음.m4a" --plan-only            # 모델 없이 분할 계획만 확인
```

## 방법 2: Google Colab (설치 없이, 무료 GPU)

1. Google Drive에 녹음 파일을 올립니다 (예: `내 드라이브/녹음/인터뷰.m4a`)
2. `transcribe_colab.ipynb`를 Colab에서 엽니다 (https://colab.research.google.com → 업로드)
3. 메뉴 **런타임 → 런타임 유형 변경 → T4 GPU** 선택
4. 셀을 위에서부터 순서대로 실행합니다. 마지막 코드 셀에서 파일 경로만 바꾸면 됩니다
5. 결과는 Drive의 `전사결과` 폴더에 저장됩니다

무료 Colab은 공식 FAQ 기준 **세션당 최대 12시간**이고, 브라우저 연결이 끊기거나 PC가 잠들면 유휴로 판정돼 더 일찍 끊길 수 있습니다
(무료 등급은 백그라운드 실행이 안 됩니다. 2026-10 기준, 수시로 바뀌므로 검증 필요).
결과를 Drive에 저장하도록 되어 있으므로, 끊기면 1·2번 셀을 다시 실행한 뒤 **마지막 셀만 다시 실행**하세요. 완료된 구간은 건너뛰고 이어서 진행합니다.

노트북을 켜 둘 수 없을 만큼 긴 파일이면 **Kaggle Notebooks**가 대안입니다. 같은 코드를 붙여 넣고 "Save & Run All"로 실행하면
브라우저를 닫아도 끝까지 돌아갑니다 (주간 GPU 한도 약 30시간, 휴대폰 인증 필요. 검증 필요: 한도는 수시로 바뀜).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 창 프로그램 (더블클릭용 화면) |
| `transcribe.py` | 전사 엔진 겸 명령어 도구 |
| `전사하기.bat` / `전사하기.command` | Windows / Mac 실행 파일. 첫 실행 때 설치까지 자동 |
| `transcribe_colab.ipynb` | Google Colab용 노트북 |
| `requirements.txt` / `requirements-gpu.txt` | 필요한 패키지 / GPU용 추가 패키지 |

## 출력 파일

| 파일 | 용도 |
|---|---|
| `이름.txt` | 문단 단위 본문. 블로그·노션·제안서에 바로 붙여넣기 |
| `이름.타임스탬프.txt` | `[00:12:34] 문장` 형식. 원본 들으며 검수·인용할 때 |
| `이름.srt` | 자막. 영상 편집기, Vrew, 유튜브 자막 업로드 |
| `이름.json` | 구간별 시작·끝·텍스트·신뢰도. 다른 도구로 가공할 때 |

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--model` | `auto` | GPU면 `large-v3`, CPU면 `large-v3-turbo`를 자동 선택. 한국어는 large-v3가 turbo보다 정확하다는 보고가 여럿(낭독체 기준 글자 오류율 약 4.9% 대 5.2%, 혼용 음성에서는 차이가 더 크다는 현장 보고. 검증 필요). 급하면 `small`, 가장 정확하게는 `large-v3` |
| `--prompt` | 없음 | 자주 나오는 고유명사·전문용어를 쉼표로. 오인식이 크게 줄어듭니다 |
| `--language` | `ko` | 영어 녹음이면 `en`, 섞여 있으면 `auto` |
| `--chunk-min` | `20` | 구간 길이(분). 메모리가 8GB 이하면 `10` |
| `--beam` | `5` | `1`로 낮추면 빨라지고 정확도는 약간 떨어짐 |
| `--device` | `auto` | GPU가 있으면 자동으로 씀. 문제가 생기면 `cpu` |
| `--outdir` | 입력 옆 `전사결과` | 결과 폴더 지정 |
| `--overwrite` | | 결과·중간 파일이 있어도 처음부터 다시 전사 |
| `--keep-work` | | 중간 파일(`.작업중`) 보관 |

## 정확도를 올리는 순서

1. **`--prompt`에 고유명사 넣기**: 사람·브랜드·제품·전문용어. 가장 효과가 큽니다
2. **녹음 품질**: 마이크를 말하는 사람 가까이. 잡음이 많으면 어떤 모델도 한계가 있습니다
3. **후편집은 AI에게**: 결과 txt를 ChatGPT/Claude/Gemini에 넣고 아래처럼 요청
   > 아래 전사문을 의미를 바꾸지 말고 맞춤법과 띄어쓰기만 고치고, 주제별로 문단을 나눠줘. 없는 내용은 절대 추가하지 마.

## 문제 해결

| 증상 | 조치 |
|---|---|
| `ffmpeg를 찾을 수 없습니다` | `pip install imageio-ffmpeg` (requirements.txt에 포함되어 있어 보통 안 생김) |
| 메모리 부족으로 꺼짐 | `--chunk-min 10` 또는 `--model medium` |
| GPU 관련 오류(cuDNN, cuBLAS, CUDA) | 오류가 나면 자동으로 CPU로 전환해 계속 진행합니다. NVIDIA GPU를 실제로 쓰려면 `.venv\Scripts\pip install -r requirements-gpu.txt`로 라이브러리를 추가 설치 (약 1GB 이상, 검증 필요: 드라이버 버전에 따라 다름, faster-whisper 공식 README의 GPU 항목 참고) |
| 첫 설치가 중간에 실패함 | 인터넷 연결 확인 후 `전사하기.bat`을 다시 실행하면 처음부터 다시 설치합니다 |
| 같은 문장이 계속 반복됨 | 이미 자동 보정하지만 남으면 `--beam 5` 유지하고 `--prompt` 추가 |
| 무음 구간에 "시청해주셔서 감사합니다" 같은 문장 | 신뢰도 낮으면 자동 제거됨. 남은 건 json의 `no_speech_prob` 보고 수동 삭제 |
| 한글이 깨져 보임(Windows) | `전사하기.bat`은 UTF-8로 설정됨. 메모장 대신 VS Code·노션으로 열기 |

이미 나와 있는 무료 프로그램으로도 "길이 제한 없는 전사"는 됩니다. 아래는 2026-10-22 기준 공식 저장소에서 "무료·무제한"을 직접 확인한 것들입니다.

| 프로그램 | 특징 | 이 도구와 다른 점 |
|---|---|---|
| **Vibe** (Windows/Mac/Linux, 무료, MIT) | 설치 → 파일 드래그 → 변환. NVIDIA·AMD·Intel·Apple GPU 모두 가속, 화자 분리 내장, GPU 메모리 부족 시 CPU로 자동 전환 | 가장 쉬움. 단 모델을 반드시 Whisper large-v3(또는 v2)로 고르고 언어를 Korean으로 고정해야 함 (기본 제공되는 Parakeet 모델은 한국어 미지원) |

## 한계 (솔직하게)

- **화자 분리 없음**: 누가 말했는지는 표시하지 않습니다. 필요하면 위의 noScribe/Vibe를 쓰거나, 이 도구에 pyannote를 붙이는 것이 다음 단계입니다
- **정확도 근거의 한계**: 공개된 한국어 벤치마크는 대부분 짧은 낭독체이고, 수 시간짜리 회의·강의에서의 독립 평가는 찾지 못했습니다. 무음·잡음 구간의 환각과 반복은 어떤 Whisper 도구에서나 나타나므로 이 도구는 VAD, 이전 문맥 비참조, 보수적 필터로 줄입니다
- **전문용어·신조어**: 학습에 없던 단어는 비슷한 소리로 적힙니다. `--prompt`와 후편집으로 보완
- **음질**: 멀리서 녹음한 회의, 겹쳐 말하기, 잡음은 정확도가 크게 떨어집니다
- **속도**: CPU만 있으면 10시간 파일은 하룻밤 걸릴 수 있습니다. 급하면 Colab GPU

## 왜 이렇게 만들었나 (수정할 때 참고)

- **직접 실행**이라 제한이 없음. 서비스들의 제한은 서버 비용 때문이지 기술 한계가 아닙니다
- **모델 자동 선택**: GPU에서는 정확도 우선(large-v3), CPU에서는 하룻밤 안에 끝나도록 속도 우선(large-v3-turbo)
- **구간 분할**: 긴 파일을 한 번에 넣으면 메모리와 반복 환각 문제가 생겨서 약 20분씩, 말 중간이 아닌 조용한 지점에서 자릅니다
- **구간별 저장**: 끊겨도 처음부터 다시 하지 않도록 구간마다 결과를 저장합니다. 원본 파일이 바뀌거나 모델·프롬프트 설정이 바뀌면 이전 결과를 자동으로 버립니다
- **GPU 실패 시 CPU 전환**: GPU 라이브러리 문제로 멈추는 일이 흔해서, 실패하면 느리더라도 CPU로 끝까지 진행합니다
